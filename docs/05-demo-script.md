# 2-Minute Demo Script: Law AI Tutor - Taxation

**Before recording**
- Use a **Chrome Incognito** window (proves the live URL works for anyone, with no saved data).
- Open https://law-ai-tutor-taxation.vercel.app. Close other tabs and turn notifications off.
- Record with **Windows + Alt + R** (Xbox Game Bar) or Loom (loom.com, free). Upload to YouTube as **Unlisted** or keep the Loom link, and check that it opens in Incognito.
- Have this answer ready to paste (it is deliberately weak):
  `Answer: The appeal is still on time. Legal basis: The taxpayer can wait for the treasurer's decision. Application: The treasurer never decided the protest. Conclusion: Tindahan can still appeal.`
